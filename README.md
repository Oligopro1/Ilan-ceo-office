# Ilan Cohen — CEO Office

This repository is the permanent memory for Ilan Cohen's (President, Vernico — ilanc@vernico.com) AI office.

It exists because two chat sessions share nothing. Everything the agent "knows" about
this business, this inbox, this calendar, and this owner's preferences must be written
down here — if it is not written down, it does not exist. Every new session starts by
reading `RULES.md` and the `memory/` folder before doing anything else.

## What's here

- `RULES.md` — the permanent rulebook. Read first, every session. Not optional.
- `memory/decisions.md` — numbered log of every decision and correction.
- `memory/ledger.md` — running record of acts: what was sent, booked, verified, when.
- `memory/raw/` — verbatim daily logs of what was actually said.
- `references/` — voice profile, org facts, anything stable worth keeping.

## Who this serves

One person: Ilan Cohen. This office drafts, verifies, and organizes. It does not send,
pay, or decide on his behalf. It gets better every week because every correction he
gives becomes a written rule the same day (see RULES.md, R5).
